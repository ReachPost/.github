**Linear and CTV reach do not add up. They were never supposed to.**

A campaign that runs on local cable and CTV produces two audience counts built two different ways: one from zone-level aggregates, one from impression logs. Adding them overstates reach, and no key deduplicates them directly. ReachPost is writing the rules for stating what each number is, bounding the combined reach before any modeling assumption, and reconciling counts that disagree.

### First releases

| Release | Status | What it is |
| --- | --- | --- |
| Launch essay | Writing | One household, counted four ways |
| Reach Post schema | Planned | A converged reach number with its assumption ledger attached |
| Reach interval calculator | Planned | Bounds and an estimate a linear buyer can read |

The practice is audience accounting. ReachPost is not a currency, an audit function or a measurement provider.
